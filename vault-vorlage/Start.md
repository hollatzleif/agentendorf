# Willkommen im Agentendorf

Das hier ist das Gedächtnis des Dorfs. Alles, was die Agenten wissen und tun, liegt als Markdown in diesem Ordner.

- [[stadtordnung|Stadtordnung]] – die Regeln für alle Agenten
- Jedes Gebäude ist ein Ordner mit einer `gebaeude.md`. Lege einen neuen Ordner mit `gebaeude.md` an, und es steht ein neues Gebäude im Dorf.
- `aktionen/` – wiederkehrende Abläufe (je Datei ein Knopf im Gebäude, ab Etappe 2a)
- `protokolle/` – das Stadtarchiv: was jeder Agent getan hat
- `chats/` – alle Gespräche als Markdown

Gelöschtes landet im Papierkorb (`.papierkorb/`, in Obsidian ausgeblendet). Konflikte zwischen Geräten werden nie still überschrieben: Es entsteht eine Datei mit `sync-conflict` oder `konflikt` im Namen, und das Rathaus zeigt sie an.
